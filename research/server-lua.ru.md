# Lua в серверных комплектах Perfect World 1.7.6

Проверка 18 ноября 2026 года. В Linear, Talolan, RuTracker/Jan2026 и Sranus 2025 найден одинаковый набор из семи Lua-файлов в дереве `pwserver`. Сравнены все 28 экземпляров. **Шесть путей побайтово одинаковы во всех четырёх комплектах.** У седьмого отличаются комментарии и форматирование; значимые токены Lua совпали.

По решению владельца проекта Lua относится к **серверному пакету**, вместе с соответствующей сборкой исполняемых файлов. Старую обвязку запуска заменяем собственными средствами, а сетевые конфигурации и шаблоны пишем для выбранного размещения и проверенных UNIX-соединений. Игровая Lua-логика сохраняется.

## Почему это часть сервера

Lua-файлы читают сами игровые процессы. Они задают обработчики и параметры поведения. Например, скрипт гильдий заполняет таблицы стоимости улучшений и числа должностей, а скрипт координатора задаёт расписание событий. Их удаление как ненужных сценариев запуска изменило бы набор серверных ресурсов.

В исследованных исходниках `LuaBase::Init` и `LuaManager::Init` создают Lua state, регистрируют API и загружают местный `script.lua` через `luaL_dofile`. Соответствующие входы уже сопоставлены с ELF рабочего комплекта. Открытие `gamed/script.lua` и `global_api.lua` также наблюдалось при прежнем запуске. Подробнее: [загрузчики и ограничения](dynamic-resources.ru.md#библиотеки-задач-навыков-и-lua), [входные файлы программ](image-files.ru.md), [холодный запуск сокращённого дерева](../experiments/image-file-validation/image-file-validation.ru.md).

## Границы проверки

Файлы извлечены из архивов и уже подготовленных статических представлений Ext. Размеры сверены с полными инвентарями; CRC сверены там, где они сохранены исходным контейнером. SHA-256 рассчитаны по полным исходным байтам. Для отличающегося `gamed/script.lua` дополнительно сравнен поток токенов без комментариев и пробельных разделителей, с сохранением строковых литералов и операторов. Другие шесть путей сравниваются полными байтами. Скрипты не исполнялись; нового запуска VM не было.

Состав пакета определяется назначением и потребителем файла. Отнесение Lua к серверному слою не означает обязательность каждого архивного Lua-файла для выбранного ELF. В частности, `skill.lua` и файл версии `global_api.lua` имеют разные роли. Потребность в старом ресурсе умений оценивается для выбранной сборки, а не по расширению файла.

Исходная коллекция `Perfect World Server` использовалась только для чтения. Производственные файлы, конфигурация и работающие службы не менялись. [Сравнение серверных комплектов](server-distribution-comparison.ru.md) · [Предложение по пакетам](package-architecture-proposal.ru.md)
