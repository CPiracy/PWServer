# Сетевые и файловые контракты PW 1.7.6 Build 4311

Снимок Debian VM за 16 ноября 2026 года показывает 11 процессов из 10 игровых бинарников. Для каждого процесса записаны аргументы, рабочий каталог, ELF, библиотеки, файловые дескрипторы и сокеты. TCP-стрелка в таблице идёт от инициатора к слушателю. Для игровых сообщений TCP и UNIX-соединения подтверждают транспорт, а смысл операций приведён по настройкам и доступному коду. [Снимок VM](evidence/runtime.json)

## Транспорт работающих служб

| Инициатор | Слушатель и порт | Контракт |
|---|---|---|
| Игровой клиент | `glinkd`, TCP `29000` | Игровой шлюз. На VM проверено прослушивание; клиентский сценарий относится к предыдущему запуску раздачи. |
| `glinkd` | `gdeliveryd`, TCP `29100` | Сессия шлюза с координатором. |
| `gs01`, `is61` | `glinkd`, TCP `29301` | Канал игровых карт к шлюзу. |
| `gs01`, `is61` | `gdeliveryd`, TCP `29300` | Канал карт к координатору и объявление игровых провайдеров в исходнике 1.7.6. |
| `gdeliveryd` | `gauthd`, TCP `29200` | Игровая авторизация. В исходнике здесь проходит проверка учётки и запрос GM-прав. |
| `gdeliveryd`, `gfactiond`, `gs01`, `is61` | `gamedbd`, TCP `29400` | GNET RPC для игрового состояния, включая чтение и запись ролей. |
| `gdeliveryd`, `gfactiond` | `uniquenamed`, TCP `29401` | GNET RPC имён и идентификаторов. |
| `gdeliveryd`, `glinkd` | `gfactiond`, TCP `29500` | Связи с гильдиями со стороны маршрутизации и шлюза. |
| `gs01`, `is61` | `gfactiond`, TCP `29600` | Операции карт с данными гильдий. |
| `gdeliveryd` | `gacd`, TCP `29702` | Связь с античитом. У `gacd` отдельно наблюдался слушатель `29712`. |
| `gauthd`, `licenseservice` | `mariadbd`, TCP `3306` | SQL к `pw176` и `licenseservice` соответственно. Наблюдались локальные сессии и подключения к отдельному адресу. |
| `gauthd`, `gs`, `gfactiond` по конфигурации и коду | `licenseservice`, TCP `127.0.0.1:33000` | Проверка лицензии через `/home/license.conf`. Слушатель наблюдался, постоянных клиентских соединений на момент снимка не было. |
| `gauthd`, `gamedbd`, `uniquenamed`, `gdeliveryd`, `glinkd`, `gfactiond`, `gs` | `logservice`, TCP `11101` и UDP `11100` | Журналирование. Набор транспортов конкретного отправителя приведён в карточке его службы. |
| `gs01` и `is61` | UNIX stream `/tmp/gssock_world1`, `/tmp/gssock_is61` | Установленные связи между двумя PID. Дополнительно у карт есть TCP-слушатели `127.0.0.1:10901` и `0.0.0.0:11971` соответственно. |

Для лицензирования и учёток `[GMysqlClient]` задаёт адрес, порт, схему и учётку. Для GNET TCP в проверенном исходнике `share/io/activeio.h:76–85` адрес разбирается через `inet_addr`. Для переноса GNET-пира между хостами первым проверяемым адресом служит числовой IPv4. DNS-имя сервиса требует отдельной пробы на бинарниках. Объявление карты и готовность маршрута требуют проверки уровня протокола поверх открытого порта. [Полевые проверки](../experiments/server-validation/server-only-validation.ru.md) · [Маршруты карт](maps.ru.md)

## Файловые условия запуска

| Владелец или потребитель | Пути | Условие |
|---|---|---|
| Каждый бинарник | Свой рабочий каталог и аргументы | В аргументах VM используются относительные имена `gamesys.conf` и игровые ресурсы; у `logservice` свой конфиг. Точные команды перечислены по службам. |
| `gs` | `gamed/config`, `gs.conf`, `gmserver.conf`, `gsalias.conf` и Lua | Один исполняемый файл запускается с алиасом карты. Карты используют общие данные и каталоги отдельных карт. |
| `gamedbd` | `gamedbd/dbhome/dbdata`, `gamedbd/dbhome/dblogs` | Персистентные данные и журнал WDB для мира. |
| `uniquenamed` | `uniquenamed/dbhome/dbdata`, `uniquenamed/dbhome/dblogs` | Своя пара данных и журнала WDB. |
| `gs`, `gauthd`, `gfactiond` | `/home/license.conf` | Абсолютный путь в проверенном клиенте лицензии. Значения относятся к окружению запуска. |
| `gs` | `/tmp/gssock_*` | Путь файлового UNIX-сокета должен быть доступен обоим игровым процессам. |
| `logservice` и отдельные демоны | `logs/`, `lualog.txt`, `skilllog.txt` и другие пути в инвентаре | У путей журналирования разные владельцы и разное время жизни. В карточках перечислены фактически открытые пути. |
