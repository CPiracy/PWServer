# План экспериментов с картами Perfect World 4311

Все прогоны рассчитаны на штатный клиент 4311 с исходными ресурсами и штатные бинарники сервера. Для холодного перехода используем стендовые Python- и Lua-скрипты. В каждом прогоне фиксируем состояние карт до действия, время, итог на клиенте и соответствующие записи серверного журнала.

| Проверка | Цель и следующий шаг |
|---|---|
| [Экран ожидания холодного телепорта](cold-teleport/plan.ru.md) | Повторить переход у Лу Фэя и проверить штатный экранный эффект до готовности `gs01`. |
| [Сеть телепортации](teleport-network/plan.ru.md) | Проверить доступность и оплату маршрута от Чэнь Яо после открытия «Тайной деревни». |
| [Ходьба и полёт по основному миру](world-movement/plan.ru.md) | Использовать дорогу до «Тайной деревни» для контроля `gs01` и отсутствия смены игрового процесса. |

Пеший контроль и проверку Сети можно провести одной сессией. Холодный телепорт у Лу Фэя требует отдельного прогона с выгруженной целью.
