# Эксперименты с картами Perfect World 4311

Прогоны выполнены на штатном клиенте и штатных бинарниках сервера. В холодных сценариях стендовый код запускал целевой GS и ждал готовности маршрута. Экран ожидания телепорта контролировали Lua-скрипты.

| Проверка | Результат |
| --- | --- |
| [Вход на выгруженную карту](map-login-autoload/map-autoload-experiment.ru.md) | Подтверждён запуск `is61` при входе и штатный экран ожидания. |
| [Телепорт через задание](cold-teleport/map-teleport-experiment.ru.md) | Подтверждён переход у Лу Фэя на холодный `gs01`. Отдельный прогон показал, что затемнение держится при дополнительной задержке запуска. |
| [Телепорт через Сеть](teleport-network/plan.ru.md) | Подтверждены открытие пункта назначения, оплата и холодный переход между двумя GS мира `1`. В тёплом прогоне переход прошёл сразу. |
| [Выгрузка пустой карты](map-unload/map-unload-experiment.ru.md) | Пустую `is61` остановили и подняли снова. Активный клиент на другом GS сохранил соединение, игра продолжалась как обычно. |
| [Ходьба и полёт](world-movement/plan.ru.md) | Необязательный контроль на полном `gs01`. Штатный сервер обрабатывает движение по территории одним процессом. |

Для выбранной конфигурации основной мир обслуживает полный `gs01`. На той же ВМ до разделения его RSS составлял 2 127 320 КиБ (2,03 ГиБ). Подготовку двух участков оставили в опыте с Сетью как способ получить холодную цель.

Для автоматической выгрузки ещё нужно проверить адресное завершение карты с подтверждением записи и вход во время остановки. Холодный переход через Сеть между разными `worldtag` остаётся кандидатом при появлении такого маршрута. [Исследование запуска, маршрутизации и завершения](../../research/maps.ru.md)
